# どうぶつレスキュー

3歳向けの、レスキュー隊の通信パッドごっこアプリです。オリジナルの動物の隊員6匹を呼び出したり、困っている人を助けるミッションでバッジを集めたりします。
文字が読めなくても遊べるように、全部の画面で声が出ます（スマホの日本語音声合成）。効果音はアプリの中で作っているので、音声ファイルはありません。

## 遊びかた

1. まんなかの光る星を押すと、パッドが起動します。
2. 隊員のアイコンを押すと呼び出し音が鳴り、つながると隊員が返事をします。「しゅつどう！」で、のりものが走っていきます。
3. 赤い「SOS」を押すとミッションです。困っている絵と声を聞いて、助けにいく隊員を選びます。正解するとバッジがもらえます（12こ）。
4. メダルのボタンで、集めたバッジを見られます。

| 隊員 | しごと | のりもの |
| --- | --- | --- |
| ホムラ（キツネ） | しょうぼう | 消防車 |
| マモル（クマ） | けいさつ | パトカー |
| ハネ（フクロウ） | そら | ヘリコプター |
| ナミ（ペンギン） | うみ | ボート |
| ガッチ（ビーバー） | こうじ | トラクター |
| ミミ（ウサギ） | きゅうきゅう | 救急車 |

隊員やミッションを増やすときは `src/data.ts` を書きかえます。絵は `src/img` に置いた名前で指定します。

## 保護者メニュー

右上の薄い歯車を **3秒長押し** すると開きます。音量、ミッションで並べる隊員の数（2〜4）、バッジを全部消す、ができます。

## 起動のしかた

ほかのアプリと同じです（`npm install` のあと `npm run dev`）。くわしくは `nazori-app/README.md` を見てください。

## 使っているもの

- 絵は [Fluent Emoji](https://github.com/microsoft/fluentui-emoji)（© Microsoft、MIT ライセンス）の 3D 画像を使っています（`src/img`、WebP に変換）。
- 隊員・名前・マーク・効果音は、すべてこのアプリのオリジナルです。
