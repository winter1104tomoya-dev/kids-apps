# なぞりがき（試作版）

3歳向けの、ひらがな・カタカナ・アルファベット・数字のなぞり書き練習アプリです。
ひらがな46文字・カタカナ46文字（清音）、アルファベット大文字26文字（小文字26文字は保護者メニューで表示）、数字0〜9をなぞれます。

## 起動のしかた（PCで動かし、同じWi-Fiのスマホで開く）

### 最初の1回だけ

1. PCに **Node.js**（LTS版）を入れます。https://nodejs.org/ja からダウンロードしてインストールします。
2. この `nazori-app` フォルダをPCの好きな場所にコピーします。
3. フォルダの中でターミナルを開きます。
   - Windows：フォルダを開き、上のアドレス欄に `cmd` と入力して Enter
   - Mac：フォルダを右クリック →「フォルダに新規ターミナル」
4. 次のコマンドを実行します（必要な部品のダウンロード。1〜2分かかります）。

   ```
   npm install
   ```

### 毎回

1. フォルダの中のターミナルで、次を実行します。

   ```
   npm run dev
   ```

2. 次のような表示が出ます。`Network:` の行のアドレスを使います。

   ```
   ➜  Local:   http://localhost:5173/
   ➜  Network: http://192.168.1.23:5173/
   ```

3. スマホ（PCと同じWi-Fi）の Chrome で、`Network:` のアドレスを開きます。
4. Windowsで「ファイアウォールでブロックされています」と出たら、**プライベートネットワーク**にチェックを入れて「アクセスを許可する」を押します。
5. 終わるときは、ターミナルで `Ctrl + C` を押します。

## スマホでの使い方のコツ

- **ホーム画面に置く**：Chrome右上の「︙」→「ホーム画面に追加」。次からはアイコンで開けます（PC側で `npm run dev` が動いている必要があります）。
- **全画面になる**：最初に画面をタッチすると全画面・縦向き固定になります。
- **アプリから出られないようにする**：Androidの「アプリ固定」を使います（設定 →「セキュリティ」または「セキュリティとプライバシー」→「アプリ固定」をオン → 最近使ったアプリの画面で Chrome のアイコンを押して「固定」）。
- **保護者メニュー**：ホーム画面右上の薄い歯車を **3秒長押し** すると開きます。音量、判定のゆるさ（やさしい・ふつう・しっかり）、アルファベットの小文字を出すかどうか、シールのリセットがあります。最初は「やさしい」です。

## 遊びかた

1. ホームで「あ」「ア」「A」「1」のどれかを押す
2. 文字を選ぶ（読み上げられます。ひらがな・カタカナは五十音表の並びで、上下にスクロールできます）
3. 書き順のアニメが流れたあと、緑の丸から矢印の向きに指でなぞる
   - 緑の丸から遠いところを触ると、丸がぴょんと跳ねて知らせます
   - 2回うまくいかないと、その画のお手本アニメがもう一度流れます。3回目は合格になります
4. 全部なぞると花丸と拍手。左の黄色ボタンで「もういっかい」、右の緑ボタンで「つぎのもじ」
5. なぞり終えた文字には、文字えらびの画面で星のシールが付きます

## お手本を少しずつ消す（4段階）

文字ごとに、お手本の出し方が4段階で進みます。なぞり画面の上の4つの丸が今の段階です。

1. **なぞる**：太いお手本の線と矢印（はじめはここから）
2. **てんせん**：細い点線と、はじまりの丸・矢印だけ。書いた線はそのまま残ります
3. **てん**：はじまりの丸と矢印だけ
4. **じぶんで**：何も出ません（書き順アニメを見てから書きます。はじまりから遠いところを触ると、丸が一瞬出て教えます）

- 書き順アニメのやり直しが出ずに書けたら、その文字は次の段階に上がり、きらきら音と「つぎは〇〇でかいてみよう」の声が出ます
- 段階が上がるほど、ずれの許容が少しゆるくなります
- 文字えらびの画面で、タイルの下の点がその文字のできた段階です
- 保護者メニューの「お手本」で、「じどう」以外を選ぶとその段階に固定できます。シールのリセットで段階も最初に戻ります

## 娘さんに試してもらうときに見てほしいこと

- 緑の丸から書き始められるか
- 「やさしい」で、合格しすぎ／しなさすぎではないか（合わなければ保護者メニューで変更）
- 線の太さ、ボタンの大きさ、読み上げの声に違和感がないか

気づいたことを教えていただければ、次の版で調整します。

## 補足

- `dist` フォルダには、組み立て済みのファイルが入っています。Node.js を使わずに、任意の静的Webサーバー（例：`python -m http.server` を `dist` で実行）からも開けます。
- 書き順データは [KanjiVG](https://kanjivg.tagaini.net/)（© Ulrich Apel、CC BY-SA 3.0）を加工したものです。`npm run kanjivg` で `src/data/` の全データ（hiragana / katakana / alphabet / lowercase / numbers）を作り直せます。文字を増やすときは `tools/kanjivg-to-json.mjs` の一覧に足してください。
- 練習の記録（シール）と設定は、スマホのブラウザ内に保存されます。アカウントは不要です。
