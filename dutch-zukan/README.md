# タッチずかん（オランダ語・試作版）

3歳向けの、絵をタッチするとオランダ語で読み上げる図鑑アプリです。
「くだもの・どうぶつ・のりもの・たべもの・やさい・むし・うみ・からだ・ふく・おうち・おそと・いろ・かず・かたち」の14のカテゴリ、全159語が入っています。

## 起動のしかた（なぞりがきと同じです）

### 最初の1回だけ

1. PCに **Node.js**（LTS版）が入っていなければ、https://nodejs.org/ja から入れます（なぞりがきで入れていれば不要です）。
2. この `dutch-zukan` フォルダをPCの好きな場所にコピーします。
3. フォルダの中でターミナルを開きます。
   - Windows：フォルダを開き、上のアドレス欄に `cmd` と入力して Enter
   - Mac：フォルダを右クリック →「フォルダに新規ターミナル」
4. 次のコマンドを実行します（1〜2分かかります）。

   ```
   npm install
   ```

### 毎回

1. フォルダの中のターミナルで、次を実行します。

   ```
   npm run dev
   ```

2. `Network:` の行のアドレス（例 `http://192.168.1.23:5173/`）を、同じWi-Fiのスマホの Chrome で開きます。
3. 終わるときは、ターミナルで `Ctrl + C` を押します。

※ なぞりがきと同時に動かすと、こちらは `5174` など別の番号になります。表示されたアドレスをそのまま使ってください。

## オランダ語の声を入れる（大事）

読み上げはスマホに入っている音声合成を使います。オランダ語の声が入っていないと、英語や日本語なまりの発音になります。

1. 保護者メニュー（右上の薄い歯車を **3秒長押し**）を開き、「ためす」を押します。
2. 「aardbei（アールトバイ）」と自然に聞こえればOKです。
3. 変な発音のときは、Androidで次を設定します。
   - 設定 →「システム」→「言語と入力」→「テキスト読み上げの出力」→ 優先エンジン「Google 音声サービス」の歯車 →「音声データをインストール」→ **Nederlands（オランダ語）** をダウンロード
   - （機種によって「ユーザー補助」の中にある場合があります）
4. アプリを開き直して、もう一度「ためす」を押します。

## 遊びかた

1. ホームでカテゴリ（いちご＝くだもの、いぬ＝どうぶつ、🔢＝かず…。たくさんあるので、画面を上下に動かすと下のほうも見られます）を押す
   - 「かず」は1〜10。数字の下に同じ数の丸が出ます
2. 絵をタッチすると、絵がぴょんと跳ねて、オランダ語で読み上げます
3. 画面の下に単語が大きく出ます。その単語を押すと、もう一度読みます
4. 左上の「＜」かスマホの戻るボタンでホームに戻ります

## 保護者メニュー

- **音量**：なし／小さめ／ふつう
- **読む速さ**：ゆっくり（最初はこちら）／ふつう
- **冠詞（de / het）**：「つける」にすると「de aardbei」「het konijn」のように読みます
- **日本語も読む**：「読む」にすると「aardbei」のあとに「いちご」と読みます
- **オランダ語の声**：声が入っているかの確認と「ためす」ボタン

## ことばを増やす・直す

`src/words.ts` に一覧があります。1行が1つの絵です。

```
{ pic: '🍓', nl: 'aardbei', art: 'de', ja: 'いちご' },
```

`pic` が絵（絵文字）、`nl` がオランダ語、`art` が冠詞、`ja` が日本語です。行を増やして保存すると、`npm run dev` 中ならスマホの画面がすぐ更新されます。
増やしたい単語を教えていただければ、こちらで追加もします。

## 補足

- 絵は [Fluent Emoji](https://github.com/microsoft/fluentui-emoji)（© Microsoft、MIT ライセンス）の 3D 画像を使っています（`src/img`、WebP に変換）。いろ・かず・かたちは、アプリの中で描いています。
- `dist` フォルダには組み立て済みのファイルが入っています（`npm run build` で作り直せます）。
- 設定はスマホのブラウザ内に保存されます。アカウントは不要です。
