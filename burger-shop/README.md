# ハンバーガーやさん

3歳向けの、お客さんの注文どおりにハンバーガーを作るごっこ遊びゲームです。
文字が読めなくても遊べるように、注文は絵と声で出ます。

## あそびかた

1. ▶ を押すとお店がひらき、動物のお客さんが来て注文を言います（例：「ハンバーグ にまいと、チーズ いちまい」）。
2. 吹き出しに、注文の具が枚数ぶん並びます。下のボタンで具をのせると、のせたぶんだけ吹き出しに緑のまるがつきます。
3. 注文どおりになったら、いちばん下の「うえのパン」をのせて完成です。
4. 注文にジュースがあるときは、言われた色のジュースを渡します。
5. お客さんが喜ぶとコインが1まいもらえます。

まちがえても責めません。「チーズが あと いちまい ほしいな」のように、次に何をすればいいかだけ伝えます。
多くのせた具はゆれて知らせるので、さわると取れます。お客さんか吹き出しをさわると、注文をもう一度言ってくれます。

自然に覚えられること：

- 数（いちまい・にまい・さんまい）と、数と絵を1つずつ対応させること
- 色（ちゃいろの ハンバーグ、きいろの チーズ、みどりの レタス、あかい トマト、ジュースの色）
- 具の名前

## 保護者メニュー

ホーム画面の右上の薄い歯車を **3秒長押し** すると開きます。

- 音量：なし／小さめ／ふつう
- むずかしさ：かんたん（具1種類・1〜2まい）／ふつう（具2種類）／むずかしい（具2〜3種類・3まいまで）
- ジュースの注文：なし／あり
- 集めたコインの数と、0にもどすボタン

設定とコインはスマホのブラウザ内に保存されます（なぞりがき・タッチずかんのデータには影響しません）。

## PCで動かす（なぞりがきと同じです）

このフォルダの中のターミナルで、最初の1回だけ `npm install`、そのあと毎回 `npm run dev` を実行し、
`Network:` の行のアドレスを同じWi-Fiのスマホの Chrome で開きます。

## 補足

- 声はスマホの読み上げ機能（日本語）を使います。音声ファイルは入っていません。
- お客さんは絵文字なので、スマホの機種によって少し見た目が変わります。
