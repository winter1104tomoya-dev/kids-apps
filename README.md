# kids-apps

3歳の娘向けのアプリです。`main` に変更が入ると、GitHub Actions が自動でビルドして GitHub Pages に公開します。

- 公開先：https://winter1104tomoya-dev.github.io/kids-apps/
- `nazori-app/` … なぞりがき（`/nazori/` で公開）
- `dutch-zukan/` … オランダ語タッチずかん（`/zukan/` で公開）
- `rescue-pad/` … どうぶつレスキュー（`/rescue/` で公開）
- `site/index.html` … アプリへの入口ページ

どれもオフラインで動く PWA です。スマホの Chrome で開き「︙」→「ホーム画面に追加」で入れます。
PCでの動かし方は各フォルダの README.md を見てください。
